Create virtual environment:
Python -m venv .venv

Activate virtaul environment:
.venv\Scripts\activate

Deactivate virtual environment:
deactivate

Install requirements.txt:
pip install -r requirements.txt

Uninstall requirements.txt:
pip Uninstall -r requirements.txt

Py to Exe:
pyinstaller --onedir --noconsole --icon icoqrlogo.ico main.py

Troubleshoot some hidden files at the time I ran pyinstaller in ubuntu.
pyinstaller --onefile --hidden-import="PIL._imagingtk" --hidden-import="PIL._tkinter_finder" myscript.py
